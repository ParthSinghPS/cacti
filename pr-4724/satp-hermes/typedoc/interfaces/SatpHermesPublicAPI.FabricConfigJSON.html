    Interface FabricConfigJSON

    Fabric Network Validation - Hyperledger Fabric configuration validation utilities.

    Description

    Configuration validation functions and type definitions for Hyperledger Fabric network integration with SATP gateways. Ensures proper fabric network setup including organization details, channel configuration, and chaincode definitions.

    See

    • INetworkOptions for general network configuration interface
    • SATPGateway for gateway implementation supporting Fabric networks
