    Configuration Validation Types - Additional validation types for network and credential configuration.

    Description

    Extended configuration validation types including Fabric connector options, key pair validation, and network identification structures. Provides comprehensive type safety for SATP gateway configuration and validation.

    See

    • FabricConfigJSON for main Fabric configuration structure
