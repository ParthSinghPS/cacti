    Interface IGatewayPersistenceConfig

    Gateway Persistence - Unified persistence layer for SATP protocol logging.

    Description

    Provides a high-level persistence interface that coordinates between local and remote repositories for SATP gateway operations. Includes configuration interface for initializing persistence with repository instances and cryptographic components.

    See

    • ILocalLogRepository for local repository interface
    • IRemoteLogRepository for remote repository interface
    • IAuditEntryRepository for audit entry repository interface
